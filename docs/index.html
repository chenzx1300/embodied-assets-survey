为具身机器人训练生成可交互工业资产 · Generating Interactive Industrial Assets for Embodied Robot Training
48+ papers surveyed 2025–2026 2 directions 12-week MVP

核心问题 / Core Question

具身机器人训练需要海量"机器人做某件事"的数据,但真实遥操作成本极高(数千美元/小时),且仿真器里没有那么多螺丝钉、连接件。

Embodied robot training needs massive "robot doing something" data, but real teleop is prohibitively expensive ($thousands/hr) and simulators lack industrial parts (screws, connectors, fasteners).

目标 / Goal: 用一段手机视频或一张图片,在几秒钟到几小时内,自动生成可被 Isaac Sim / MuJoCo / Genesis 读取的几何精确、物理可信、可交互的工业资产。

Goal: From a phone video or a single image, in seconds-to-hours, automatically generate geometry-accurate, physics-plausible, interactive industrial assets readable by Isaac Sim / MuJoCo / Genesis.

双轨调研 / Two Directions

本调研分两个互补方向展开,根据输入模态选择:

📹 Direction A · 视频 → 可交互资产

输入 / Input: 手机拍摄的工业操作视频

输出 / Output: 4D Gaussian + 物理反演 → USD/URDF

适用 / Use: 已有动作数据、需要时序几何、含铰链/滑动件

核心引擎 / Engines: OVOWNVIDIA SimFoundry

→ 进入 Direction A / Open

🖼️ Direction B · 图片 → 可交换资产

输入 / Input: 单张工业零件图片

输出 / Output: TRELLIS.2 / Amodal3R → 可交换 USD

适用 / Use: 单件重建、批量资产生成、目录式数据扩展

核心引擎 / Engines: TRELLIS.2Amodal3R

→ 进入 Direction B / Open

关键结论 / Key Conclusions

  1. VLM 介入深度谱(0–4):LLM 不应做主力,只在"语义路由"(档位 2)介入最经济 / LLM shouldn't do the heavy lifting; "semantic routing" (level 2) is the sweet spot.
  2. OVOW + NVIDIA SimFoundry 双引擎:学术 + 工业互补,无需从零造轮子 / Academic + industrial complementarity; no need to reinvent.
  3. 光轮智能是数据上游:80% 头部具身团队都在用其数据,直接合作优于自建 / 80% of top embodied teams use its data; partnership beats in-house.
  4. TRELLIS.2 是当前 SOTA 几何生成器:开源 + 商业可用,优先采用 / SOTA geometry generator; open-source + commercially usable.
  5. 3 个月实施 MVP:W1 商务并行启动 + OVOW/SimFoundry 双引擎并行,可压到 12 周 / W1 biz-dev parallel start + dual-engine parallel → 12 weeks.
