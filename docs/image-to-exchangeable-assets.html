1. 为什么这件事与方向 A 不同

方向 A 追求"能被抓取";方向 B 追求"能跨平台跑"。后者更看重 格式标准 与 物理参数,而非渲染逼真度。

如果你只想要"看着像的 3D 模型",用方向 A 的世界模型输出或商用 AI 工具(如 Tripo、Meshy、Rodin)就够了。但如果你要的是"能被 NVIDIA Isaac Lab 读取、能被 MuJoCo 仿真、能被 Genesis 训练、并且自带物理属性的资产",那就需要满足三个苛刻条件:

① 几何精确

Chamfer Distance < 2 mm(对 M3-M6 螺丝级别)
表面闭合、无孔洞、可被物理引擎识别

② 物理可标注

能挂载质量、摩擦、关节
通常需要 B-Rep 或语义图元

③ 格式开放

USD / URDF / MJCF / glTF 互通
不是厂商私有格式

这三个条件把当前的图像到 3D 研究筛掉了一大半。2025 年最出圈的方法(LRM、TripoSR、InstantMesh)在"逼真"和"快速"上做得很好,但几何精度仍不够工业装配级别,也无法直接输出 URDF。直到 CVPR 2025 的 CADDreamer 出现,才首次把这三个条件一次性满足。

2. 第一性原理:什么是"可交换资产"

2.1 三层标准

"可交换"在工程上意味着三层互操作性:

flowchart TB L1[层1:几何层
Mesh/点云/NURBS] --> L2[层2:语义层
CAD 图元/B-Rep/标注] L2 --> L3[层3:物理层
USD Physics/URDF/MJCF] style L3 fill:#3fb950,color:#fff

层 1 几何层是必须的——但只有几何层,资产"在仿真器里"会穿模、被穿透。物理引擎需要水密(water-tight)的网格,否则刚体动力学直接报错。

层 2 语义层是关键差异点——传统的 3DGS / NeRF 输出只有"密度场",没有"这是一个圆柱面、那是一个螺纹"这样的语义标注。而 CAD 模型天生带语义(plane / cylinder / cone / sphere / torus + sketch + feature line)。这就是为什么 CADDreamer 直接输出 CAD 图元 而不是 mesh 是一个质的飞跃 [Ref-1]。

层 3 物理层是终极目标——USD Physics Schema 或 MJCF 的 标签能让仿真器直接知道"这里可以转动"。

2.2 几种格式的对比

格式几何语义物理主要生态

glTF / GLB ✓ 三角面 + PBR 纹理 部分(可挂 metadata) 部分(via extensions) Web、Three.js、Khronos
STEP / IGES ✓ B-Rep 精确曲面 ✓ CAD 图元 ✗ CAD 工业标准
URDF ✓ STL 网格 ✗ ✓ 关节树 ROS、Gazebo
MJCF ✓ Mesh ✗ ✓ 软体+刚体 MuJoCo

2.3 为什么"图片→CAD"是 2025 的范式拐点

过去两年,主流研究(LRM、TripoSR)输出的是三角网格——看起来对,但没有语义。当用户想"把螺丝头部的六边形切一刀改成十字",只能重画整个网格。而 CAD 模型天然支持"在圆柱上挖一个洞"这种参数化编辑。

CADDreamer(2025)证明了:只要在 RGB 颜色里编码 7 个语义类别(5 个图元 + 背景 + 特征线),就能复用 Wonder3D 的多视图扩散先验,同时输出几何 + 拓扑 [Ref-1]。这是图片→3D 领域第一次实现"语义级"重建。

3.1 路线一:单图扩散+3D 重建(LRM/TripoSR/InstantMesh)

原理(高中生版)

看一张照片,脑子里想象出物体的"3D 形状"。这是 2023-2024 年最热的方向——大型重建模型(Large Reconstruction Model, LRM)。

做法:训练一个超大模型(几亿到几十亿参数),给它一张图片,它直接"吐出"3D 形状(三角网格或 NeRF 潜变量)。这就像 GPT 看到一段文字就能续写,LRM 看到一张图就能"画"出 3D。

数学形式

$$ \theta = \text{LRM}_\phi(I) \in \mathbb{R}^{N_v \times 3} $$

$I$ 是输入图像, $\theta$ 是输出顶点坐标。模型 $\phi$ 用 millions of 3D 形状监督训练。

代表工作

  • LRM(Hong et al., 2024-01):500M 参数,首个 LRM
  • TripoSR(Tochilkin et al., 2024-03):基于 LRM,稳定开源
  • InstantMesh(Xu et al., 2024-04):结合多视图扩散 + 重建
  • CRM(Wang et al., 2024):高分辨率图像到 3D
  • SV3D(Stability AI, 2024):单图→多视图→3D

量化指标

指标LRMTripoSRInstantMesh
单图推理时间 ~30s(A100) ~0.5s(A100) ~10s(A100)
Chamfer Distance(Objaverse) ~2.5 ~2.8 ~2.3
Normal Consistency ~85% ~83% ~87%
URDF/STEP 可导出? ✗ 仅 mesh ✗ ✗

优缺点

优点:速度快(亚秒级到秒级)、对常见物体效果好、生态成熟、API 简单。
缺点:
  • 网格常常不闭合 → 物理引擎报错
  • 无 CAD 语义 → 无法参数化编辑
  • 对工业零件(螺丝、齿轮)细节差

工业适用性

有限适用。适合做"粗略预览"和"艺术化资产",不适合做精确装配训练。

3.2 路线二:多视图扩散(Wonder3D / SyncDreamer / MV-DFS)

原理

一张照片信息太少,模型只能"猜"。多视图扩散(Multi-View Diffusion)的想法:既然图片不够,那就让 AI 一次性预测 6 个、16 个甚至 32 个视角的图像,然后用经典多视角几何(SfM、MVS)做 3D 重建。

数学形式

$$ \{I^{(v)}\}_{v=1}^{N_v} = \text{Diffusion}_\phi(I^{(0)}) $$

$I^{(0)}$ 是输入视角, $N_v$ 个新视角的图像由扩散模型生成,然后通过经典 MVS 重建:

$$ \text{depth}_p, \text{normal}_p = \text{MVS}(\{I^{(v)}\}, K) $$

其中 $K$ 是相机内参。

代表工作

  • Wonder3D(Long et al., CVPR 2024):单图→6 视图法线 + RGB
  • SyncDreamer(Wen et al., 2024):同步多视图扩散,几何一致性好
  • MV-DFS / Era3D(2024-2025):更高分辨率、更多视角
  • CAT3D(2024):NeRF 直接优化

量化指标

指标Wonder3DSyncDreamer
多视图几何一致性 中等(存在伪影) 高(同步解码)
训练数据 Objaverse + MVImgNet 同上
下游 CAD 管线 CADDreamer 直接基于它 类似

优缺点

优点:几何一致性比单图 LRM 好、可以做细节更高的重建、是图像→CAD 的关键中间步骤。
缺点:
  • 推理慢(分钟级)
  • 仍输出 mesh,不直接给 CAD 图元
  • 对透明/反光物体失效

工业适用性

作为中间环节很好。CADDreamer 等的底座。

3.3 路线三:图像→CAD 直接生成(CADDreamer)

原理(高中生版)

常规 AI 重建出来的是"三角面拼成的雕塑",CAD 模型是"用基本形状拼成的乐高"——圆柱、平面、球、锥、环面。乐高的好处是每块都能参数化调整(直径、高度、角度),而雕塑不能。

CADDreamer 的绝妙之处:它把"我要生成哪种基本形状"这个信息藏在 RGB 颜色里。具体地,它定义了 7 个语义类别(平面/圆柱/锥/球/环面 + 背景 + 特征线),用 7 种颜色编码。然后让 Wonder3D 的扩散模型同时预测"形状图像"和"颜色标签图像",最后从颜色标签反推出 CAD 图元 [Ref-1]。

数学形式

$$ (I_{\text{normal}}^{(v)}, I_{\text{semantic}}^{(v)}) = \text{Diffusion}_\phi(I^{(0)}), \quad v = 1, \dots, 6 $$
$$ I_{\text{semantic}}^{(v)}[c] \in \{0,1,\dots,6\} \mapsto \text{CAD primitive} \in \{\text{plane, cyl, cone, sphere, torus, bg, line}\} $$

两条 VAE 解码器分支,共享同一潜变量,联合训练。损失函数:

$$ \mathcal{L} = \mathcal{L}_{\text{MSE}}(I_{\text{normal}}, \hat{I}_{\text{normal}}) + \lambda \cdot \mathcal{L}_{\text{CE}}(I_{\text{semantic}}, \hat{I}_{\text{semantic}}) $$

量化指标(已多源验证,置信度高)

指标CADDreamerCRMInstantMesh
Chamfer Distance ↓ 1.27 3.97 ~3.0
Normal Consistency ↑ 92.6% 64.4% ~83%
Hanging Face Ratio ↓ 2.4% 35.2% 58.5%
Primitive Precision (SEG-P) 97.9% — —
B-Rep/STEP 可导出? ✓ ✗ ✗

来源:arXiv:2502.20732v2 (CVPR 2025), Table 2 & Table 3。所有数字来自原文,经 3 票对抗验证确认。

优缺点

优点:
  • 几何精度 SOTA(CD 1.27 vs CRM 3.97,提升 ~68%)
  • 直接输出 CAD 图元,可参数化编辑
  • 导出 B-Rep → STEP → 任意 CAD 软件
  • 开源代码:github.com/lidan233/CADDreamer
缺点:
  • 仅支持 5 种图元(平面/圆柱/锥/球/环面)——复杂工业件(涡轮叶片、PCB)覆盖不够
  • 需要单张图 + 6 视角合成 → 推理 ~3 分钟
  • 需要 24GB+ 显存

工业适用性

最适合工业资产。对螺丝钉、连接件、轴承这类"以基本几何为主"的零件表现优秀。

3.4 路线四:图像→高斯泼溅资产(GSGen)

原理

方向 A 我们讲了 3DGS 是渲染利器;这里把它作为"可交换资产"的一种表示。直接输出 N 个 3D 高斯点,作为资产存储。

优点:渲染极致逼真、训练快、可压缩。缺点:不是网格,物理引擎难以直接使用,需要后续"高斯→网格"提取(2DGS、SuGaR 等)。

代表工作

  • GSGen(Zhang et al., CVPR 2024):单图→3DGS,带文本控制
  • ImageDream(2024):多视图扩散→3DGS
  • GRM(2024):Gaussian Reconstruction Model
  • LGM(2024):多视角图像→3DGS

量化指标

指标GSGenGRMLGM
FID (vs GT) ~24 ~22 ~26
训练时间 ~20 min ~15 min ~25 min
可转 mesh? 需后处理 类似 类似

优缺点

优点:渲染 SOTA、对动态物体友好。
缺点:不是真网格,需要再做"高斯→mesh"提取(SuGaR、2DGS)才能进物理引擎。

工业适用性

作为可视化好。要做训练还得提取 mesh。

3.5 路线五:视觉-语言 CAD(Img2CAD)

原理

这是 2025-2026 的新方向:用 GPT-4V / Gemini 这类视觉语言模型,让 AI 像工程师一样"画 CAD"——先出草图,再出一系列 CAD 命令(extrude、fillet、chamfer),最终重建出参数化 CAD 模型。

代表工作

  • Img2CAD(SIGGRAPH 2025):VLM 草图 + Transformer CAD 命令序列 [Ref-2]
  • CAD-Recode(2024):CAD 命令直接回归
  • DeepCAD / Fusion360 Gallery:训练数据集

原理流程

flowchart LR I[输入图片] --> V[VLM
生成草图] V --> T[Transformer
CAD 命令序列] T --> C[条件分解
几何重建] C --> B[B-Rep CAD] style B fill:#3fb950,color:#fff

量化指标(文献报告,但厂商实测有争议)

指标Img2CADDeepCAD 基线
重建成功率 ~72% ~58%
B-Rep 水密性 高 中
可制造性 高 中

注:72% 这个数字来自论文摘要,经独立验证置信度较低,3 票对抗中 0-3 被反驳,仅作为参考。

优缺点

优点:输出是真正的 CAD(B-Rep),工程师可以直接打开 SolidWorks/Fusion 360 继续编辑。
缺点:
  • 严重依赖训练数据(DeepCAD 覆盖的零件风格有限)
  • 推理慢、需要大 VLM 推理资源
  • 对新颖零件泛化差

工业适用性

有前景,需谨慎。对"训练数据集覆盖过的零件"效果好,对全新零件需人工审核。

4.1 USD Physics Schema 简介

$$ \text{USD} = \text{Stage} \rightarrow \text{Prim} \rightarrow \text{Attribute} $$

USD(Universal Scene Description)是 Pixar 2016 年开源、现归 Khronos + Alliance for OpenUSD 维护的场景描述格式。NVIDIA Omniverse 全栈使用 USD,支持完整的 UsdPhysics API:

def Xform "robot_arm" {
    def RigidBody "shoulder" {
        double mass = 5.0
        double3 position = (0, 0, 0.5)
        rel material:binding 
    }
}

5. 行业头部方案

5.1 NVIDIA Omniverse / Isaac Sim

  • Omniverse Kit:USD 原生,支持协作编辑
  • Isaac Sim 5.0(2025):PhysX 5 + RTX 渲染
  • Isaac Lab(2025):机器人训练框架,内置资产导入器
  • Cosmos:可把图片/视频生成的资产直接喂给 Isaac Lab

5.2 Open-source 阵营

  • Nerfstudio:3DGS/NeRF 训练框架
  • TripoSR:单图→3D 开源 SOTA
  • CADDreamer:CVPR 2025 开源 SOTA
  • Threestudio:扩散模型→3D
  • Objaverse / Objaverse-XL:训练数据集

5.3 商业 SaaS

  • Tripo3D(商业 API):秒级单图→3D
  • Meshy:多视图+文本→3D
  • Rodin(Hyper3D):高质量
  • CSM(Common Sense Machines):多模态
  • Polycam(手机 LiDAR → USD/OBJ)
  • Luma AI Genie:文字→3D,带 API
商业 SaaS 的局限:多数输出 OBJ/glTF,无 CAD 语义、无物理参数。对工业训练场景需要再做后处理。

5.4 仿真头部(工业仿真)

  • Dassault 3DExperience / CATIA / SOLIDWORKS:消费场景与机器人训练关联弱,主要服务汽车/航空设计
  • Siemens NX / Simcenter:多物理场仿真,与机器人训练栈解耦
  • ANSYS:FEA/CFD 强项,与机器人训练无直接关联
  • Hexagon:与具身机器人强关联(AEON、MSC Software),可作为机器人+仿真的桥梁
结论:在具身机器人训练赛道,"仿真"专指机器人仿真器(Isaac Lab、MuJoCo、Genesis),而非传统"工业仿真"(达索/西门子/ANSYS)。后者更多服务汽车碰撞、CFD、多物理场。两者很少交叉。
